# HistoLab — مختبر الهيستوباثولوجي والسيتولوجي

مرجع علمي ثنائي اللغة (عربي / إنجليزي) لفنيي وأخصائيي مختبرات الهيستوباثولوجي والسيتولوجي.

**الموقع:** https://mam87.github.io/Histolab/

## المحتوى
- الأساسيات: مراحل معالجة الأنسجة، أنواع العينات، معايير الجودة قبل التحليل
- الهيستوباثولوجي: التثبيت، الفحص العياني، المعالجة، الطمر، القطع (Microtomy)
- السيتولوجي: مسحة عنق الرحم (Bethesda 2014)، FNAC و TBSRTC 2023، سوائل الجسم
- الصبغات: H&E، Pap، Giemsa، الصبغات الخاصة، IHC والتشخيص المرافق (HER2-low/ultralow، CLDN18.2، PD-L1، HER2 في سرطانات المعدة والمريء)
- البروتوكولات المعيارية (SOPs) والسلامة المخبرية (حدود التعرض للفورمالدهيد ACGIH / OSHA)
- دليل البنش: جداول حل المشكلات (التثبيت والمعالجة، القطع، H&E، IHC) وبطاقات عملية (المقاطع المجمدة، عينات السيتولوجي، Cell block، التضمين، ضبط الصبغات الخاصة، تتبع العينة) ملخّصة من Bancroft و Carson و Kiernan و Koss و Dabbs ودليل Dako
- مستجدات موثّقة ومؤرّخة مع روابط لمصادرها الرسمية
- 24 مرجعاً علمياً

## التقنية
صفحة واحدة `index.html` (HTML/CSS/JS بدون أي مكتبات)، أيقونات SVG مضمّنة (Lucide)، خط IBM Plex Sans Arabic، تُنشر عبر GitHub Pages.

## تحديث المستجدات
المستجدات موجودة في المصفوفة `ND` داخل `index.html`. لكل عنصر: التاريخ `d`، التصنيف `c`، رابط المصدر `u`، والنص بالعربية `ar` والإنجليزية `en`. أضف العناصر الأحدث في أعلى المصفوفة، وحدّث تاريخ "آخر مراجعة" في قسم المستجدات والتذييل.
